# k-GNN Interpretation with GIN-Graph

Code for a bachelor's thesis comparing 1-GNN and 1-2-GNN classifiers
through model-level explanations generated by GIN-Graph, on MUTAG and
PROTEINS. See `thesis.pdf` for the full write-up and results.

## Setup

```bash
git clone https://github.com/tagesk-tech/Interpreting-k-GNN-Expressivity-via-GIN-Graph.git
cd Interpreting-k-GNN-Expressivity-via-GIN-Graph

python -m venv venv
source venv/bin/activate

pip install torch torch-geometric torch-scatter torch-sparse
pip install -r requirements.txt
```

PyTorch and PyTorch Geometric are installed first because the wheels
depend on the local CUDA / Python version. Adjust the index URL if you
need a CUDA build (see the PyG install docs).

Quick sanity check:

```bash
python test_setup.py
python test_integration.py
```

## Reproducing the experiments

The pipeline has four stages. Run them in order; each stage reads the
checkpoints written by the previous one.

### 1. Train the k-GNN classifiers

```bash
python train_kgnn.py --dataset mutag    --model 1gnn  --epochs 100
python train_kgnn.py --dataset mutag    --model 12gnn --epochs 100
python train_kgnn.py --dataset proteins --model 1gnn  --epochs 100
python train_kgnn.py --dataset proteins --model 12gnn --epochs 100
```

Writes `checkpoints/{dataset}_{model}.pt`.

### 2. Train the GIN-Graph generators

One generator per (dataset, model, target class), eight total:

```bash
for dataset in mutag proteins; do
  for model in 1gnn 12gnn; do
    for class in 0 1; do
      python train_gin_graph.py --dataset $dataset --model $model \
                                --target_class $class --epochs 300
    done
  done
done
```

Writes `gin_checkpoints/{dataset}/{model}_class{N}.pt`. Intermediate
samples and checkpoints from the run go to
`gin_checkpoints/{dataset}/training/`.

### 3. Analyse one checkpoint at a time

```bash
# k-GNN test-set evaluation
python research.py gnn --dataset mutag --model 1gnn

# GIN-Graph explanations from an existing checkpoint
python research.py gin --dataset mutag --model 1gnn --target_class 0
```

Outputs go to `results/{dataset}/{model}/` (k-GNN) or
`results/{dataset}/{model}_class{N}/` (GIN-Graph).

### 4. Compare generated vs real datasets

```bash
python compare_datasets.py --dataset mutag    --num_samples 500
python compare_datasets.py --dataset proteins --num_samples 500
```

Generates 500 graphs per class from each GIN-Graph checkpoint, then
runs structural fidelity tests, cross-model classification, and a
t-SNE embedding plot. Outputs land in `results/{dataset}/comparison/`.

## Datasets

MUTAG (188 molecules) and PROTEINS (1113 protein graphs) are
downloaded automatically by PyTorch Geometric on first run, into
`data/`. DD is supported in the codebase but excluded from the study
because GIN-Graph training is too slow on it.

## Configuration

All hyperparameters live in `config.py`: hidden dims, layer counts,
dropout, learning rate, GIN-Graph latent dim, dynamic-weighting
schedule, and the size / node-type regularisation weights. The
`from_dataset()` factory on `DataConfig` provides per-dataset
defaults.

## Extended models

The codebase also supports `--model 123gnn` (1-2-3-GNN with triplet
message passing) and `--dataset dd`. Both work end to end but are
outside the scope of the thesis study; expect significantly longer
training times.
